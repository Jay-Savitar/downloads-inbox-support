Downloads Inbox Support

Organize files

Open Inbox, select the files you want to organize and open the preview. Check the final names and destinations before confirming.

Restore a file

Open History and select its organization. Choose Restore File or Restore Organization. If a file is missing, return the same file to the recorded location and retry. If folder access is unavailable, use Reauthorize and select the original folder.

Restore Pro

Open Settings → General. If verification is unavailable, return to the app with the original purchasing account available and use Retry Verification. You can also choose Restore Purchases. Manual organization and history remain available.

Contact support

Open a support request on GitHub. Requests are public. Include your macOS and app versions and the steps you took. Omit private filenames, receipts and account details.
